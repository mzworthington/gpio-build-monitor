Privacy policy

Last updated 3 September 2026.

This page says what the public build monitor does with information when you use monitor.mzworthington.co.uk. It is a plain-language notice, not legal advice.

The site is built by Matthew Z Worthington.

Product analytics (PostHog)

The public status page uses PostHog Cloud EU (via a first-party ingest host) so we can see which pages people open.

We configure PostHog with cookieless tracking: it does not write PostHog cookies or use local/session storage for identity, and we do not call identify(). Counts use a privacy-preserving hash on PostHog’s servers. Session replay is off on this site.

That is why this site does not show a cookie banner for PostHog. Cloudflare or the browser may still use their own cookies for hosting or security.

PostHog’s own terms and privacy policy apply to data they process for us.

Hosting

The website is a Cloudflare Worker with static files. Those systems receive normal web-request metadata (for example IP address at the edge) as part of serving the site. A separate Cloudflare Web Analytics beacon may also run for visit counts.

What we do not do

We do not sell your data. We do not run ads. You do not need an account to view status.

Asking us to delete something

If you think we hold personal data about you in PostHog or elsewhere, open an issue on github.com/mzworthington/gpio-build-monitor and say what you want removed. We will use PostHog’s deletion tools where they apply.

Changes

If this notice changes in a material way, we will update the date at the top.
